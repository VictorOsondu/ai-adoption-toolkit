# Security Policy

This repository contains public adoption-planning templates. Please do not include private, confidential, client, customer, student, ministry, organisational, personal, financial, legal, health, credential, regulated, security, or proprietary information in public issues, pull requests, examples, screenshots, survey responses, logs, or case studies.

## Reporting Sensitive Issues

If sensitive material has been published here, contact the maintainer through AI Tutorium rather than repeating the material in a public issue.

## Public Contribution Rule

Use public or synthetic examples by default. Named field reports should be included only when the context is already public and permission is clear.
