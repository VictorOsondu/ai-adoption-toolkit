# AI Use Policy Check

A lightweight check for whether an AI use policy is practical enough for staff to follow.

Last reviewed: 2026-07-24. See [sources and verification notes](../sources.md).

## Policy Basics

| Question | Yes / No / Partial | Notes |
| --- | --- | --- |
| Does the policy say who owns AI adoption? | | |
| Does it say which tools are approved? | | |
| Does it say what data must not be entered into public tools? | | |
| Does it cover human review before public or client-facing use? | | |
| Does it explain how to disclose AI use when required? | | |
| Does it explain what to do when something goes wrong? | | |
| Has it been read by the people expected to follow it? | | |
| Is it reviewed on a known cadence? | | |

## Minimum Usable Standard

A policy is not usable if staff cannot answer these five questions without guessing:

1. Which tools can I use?
2. What data must I keep out?
3. What work needs human review?
4. When must I disclose AI use?
5. Who do I contact when unsure?
